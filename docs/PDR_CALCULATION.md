# PDR Calculation - Final Implementation

## Problem

PDR (Packet Delivery Ratio) values were exceeding 100% (e.g., 328%, 464%, 142%), which is mathematically impossible.

**Root Cause**: In multi-hop protocols (VBF, DBR, Flooding), the same packet can arrive at the sink via multiple paths. Each arrival was being counted separately, causing the received count to exceed the sent count.

## Solution: Unique Packet UID Tracking

The solution uses `std::set<uint64_t>` to track unique packet UIDs, automatically deduplicating packets that arrive via multiple paths.

### Implementation

#### 1. Global Set for Unique Packet Tracking

```cpp
// Global set to track UNIQUE packet UIDs received at sink
static std::set<uint64_t> g_receivedPacketUids;

// Callback for sink routing - tracks unique packets only using packet UID
void SinkPacketCallback(Ptr<const Packet> packet) {
  uint64_t uid = packet->GetUid();
  g_receivedPacketUids.insert(uid);  // std::set automatically deduplicates
}
```

**Location**: Lines 34-40 in `uwsn-research_v2.cc`

#### 2. Connect Trace Callback

```cpp
// After createDevice(sinksCon);
g_receivedPacketUids.clear();  // Reset for each run
Ptr<AquaSimNetDevice> sinkDev = DynamicCast<AquaSimNetDevice>(sinksCon.Get(0)->GetDevice(0));
sinkDev->GetRouting()->TraceConnectWithoutContext(
  "PacketReceived",
  MakeCallback(&SinkPacketCallback)
);
```

**Location**: Lines 221-227 in `uwsn-research_v2.cc`

#### 3. Calculate PDR Using Unique Count

```cpp
int senderSentPkts = senderDev->TotalSentPkts();  // Packets generated by sender
int sinkRecvPkts = g_receivedPacketUids.size();   // UNIQUE packets received at sink

// PDR = unique packets received / packets sent (guaranteed 0-100%)
double pdr = (senderSentPkts > 0) ? (double)sinkRecvPkts / senderSentPkts : 0.0;
```

**Location**: Lines 258-264 in `uwsn-research_v2.cc`

## How It Works

### Packet Flow Example

```
Sender generates packet (UID=100)
    |
    v
Packet travels via Path A --> Arrives at Sink --> UID 100 added to set
    |
    v
Same packet travels via Path B --> Arrives at Sink --> UID 100 already in set (ignored)
    |
    v
Final count: g_receivedPacketUids.size() = 1 (not 2)
```

### Why This Works

1. **ns-3 Packet UIDs**: Every packet in ns-3 has a unique ID (`GetUid()`) that remains constant throughout its lifetime
2. **std::set Deduplication**: `std::set<uint64_t>` automatically ignores duplicate insertions
3. **Trace Source**: Uses Aqua-Sim-NG's standard "PacketReceived" trace source
4. **No Protocol Changes**: Works with VBF, DBR, and Flooding without modification

## Technical Details

### Aqua-Sim Trace Source

The implementation uses Aqua-Sim-NG's "PacketReceived" trace source:

```cpp
// From aqua-sim-routing.cc
.AddTraceSource("PacketReceived",
  "Trace source indicating a packet has been delivered to the upper layer.",
  MakeTraceSourceAccessor(&AquaSimRouting::m_routingRxCbTrace),
  "ns3::AquaSimRouting::PacketReceivedCallback")
```

This trace fires in `AquaSimRouting::SendUp()` for every packet sent up by the routing layer, including:
- Packets where node is destination
- Packets node is forwarding

Our callback filters using packet UID to count only unique packets.
