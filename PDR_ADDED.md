## How PDR is Calculated

### End-to-End Measurement
```
PDR = (Packets Received at Sink) / (Packets Sent by Sender)
```

**NOT** network-wide totals (which would be > 100% due to forwarding)

### Implementation
```cpp
senderSentPkts = senderDev->TotalSentPkts();    // Packets generated by sender
sinkRecvPkts = sinkDev->GetRouting()->SendUpPktCount();  // Packets delivered to sink application
pdr = sinkRecvPkts / senderSentPkts;  // Ratio (0.0 to 1.0)
```

## Why This Matters

✅ **PDR is now the PRIMARY metric** for protocol comparison
✅ Shows which protocol successfully delivers the most packets
✅ Essential for publication (PDR is standard in UWSN papers)
✅ Complements energy metrics (high PDR with low energy = best)
